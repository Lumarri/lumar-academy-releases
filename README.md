# Lumar Academy

Aprende matemáticas, lógica y física con tutoras anime, una interfaz kawaii y ejercicios que crecen contigo.

## Descargar para Android

**[Descargar Lumar Academy](https://github.com/Lumarri/lumar-academy-releases/releases/tag/v1.0.0-preview.1)**

En la release, abre **Assets** y descarga `Lumar-Academy-v1.0.0-preview.1.apk`. Es una versión de prueba para Android, compilada en modo release y firmada con la clave de desarrollo actual. iOS todavía no tiene una descarga publicada.

Este repositorio contiene la presentación y las descargas oficiales. El código fuente se mantiene en un repositorio privado. Los archivos «Source code» que añade GitHub contienen únicamente esta presentación y sus capturas.

## Tu próxima aventura

**12 cursos · 97 etapas · 2630 ejercicios**, con teoría, ejemplos, pistas, soluciones paso a paso y progreso local.

Álgebra, geometría, trigonometría, precálculo, logaritmos, potencias, ecuaciones de segundo grado, álgebra lineal, lógica, cálculo, física clásica introductoria y Física 1 universitaria con mecánica, ondas y fluidos.

Un campus con diálogos, favoritos de las tutoras, búsqueda de cursos, fórmulas LaTeX y temas claro y violeta oscuro. También incluye un cuaderno de curiosidades, lecturas recomendadas y repaso de lo que te cuesta.

## Novedades

Las nuevas versiones se publican en [Releases](https://github.com/Lumarri/lumar-academy-releases/releases). Para instalar la app descarga la **APK** de Assets; los ZIP y TAR automáticos de GitHub no son instaladores.

La app guarda el progreso en tu dispositivo. Desinstalarla o borrar sus datos elimina ese progreso.
